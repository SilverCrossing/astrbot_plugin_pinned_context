### 关键修复：SQLAlchemy 2.0 兼容性（showstopper）

发现 AstrBot 依赖 `sqlalchemy[asyncio]>=2.0.41`。SQLAlchemy 2.0 要求所有原生 SQL 必须用 `text()` 包裹，否则抛 `ObjectNotExecutableError`。

- `block_manager.py`：所有 `session.execute("SQL ?", params)` 改为 `session.execute(text("SQL :param"), {"param": val})`
- `db.py`：`init_db` 中建表 SQL 也用 `text()` 包裹
- 占位符从 `?`（位置参数）改为 `:paramname`（命名参数），参数从 tuple 改为 dict
- 未修复前插件完全无法运行，现已修复
