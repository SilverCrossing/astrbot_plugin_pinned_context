### 更新：对照 AstrBot 官方文档深入审查

搜索并获取了 AstrBot 官方文档（https://docs.astrbot.app/）和 GitHub 源码，对照后发现了更严重的问题，更新了 `IMPLEMENTATION_REVIEW.md`：

- **致命 Bug（BUG-1）**：`context.get_config()` 读取的是全局配置而非插件配置，应改用 `__init__(self, context, config: AstrBotConfig)` 参数接收。导致 `plugin_config.yml` 中所有配置项从未生效。
- **严重 Bug（BUG-2）**：`context._db` 是私有属性，官方有公开方法 `context.get_db()` 返回 `BaseDatabase` 实例，应改用 `context.get_db().get_db()`。
- **严重 Bug（BUG-3）**：向 `system_prompt` 追加变化内容会破坏 prompt 缓存（7-20x 费用），官方推荐用 `req.extra_user_content_parts` + `TextPart` 注入动态上下文。
- **配置格式过时**：应从 `plugin_config.yml` 迁移到 `_conf_schema.json`（JSON Schema 格式），框架据此自动生成 WebUI 配置面板。
- **权限控制 API 已确认**：`@filter.permission_type(filter.PermissionType.ADMIN)` 可限制命令仅管理员可用。
- **数据库建表方式**：AstrBot 核心使用 SQLModel（SQLAlchemy + Pydantic）定义表，而非原生 SQL。
- Star 基类内置 KV Store（`put_kv_data`/`get_kv_data`/`delete_kv_data`），但钉选块需复杂查询，自建表合理。
